# AudioCut 30s

AudioCut 30s é uma ferramenta gratuita de edição de áudio que permite cortar automaticamente os primeiros 30 segundos de qualquer arquivo de áudio compatível com o navegador.

Desenvolvido em HTML5, CSS e JavaScript, o projeto possui uma interface minimalista com fundo totalmente preto, inspirada no design do Google e da Apple.

# Funcionalidades

- Upload de arquivos por seleção ou arrastar e soltar.
- Suporte a MP3, WAV, M4A, AAC, OGG, FLAC e outros formatos compatíveis com o navegador.
- Corte automático dos primeiros 30 segundos.
- Pré-visualização do áudio processado.
- Download do resultado em formato WAV.
- Processamento diretamente no navegador.
- Não exige cadastro ou instalação.
- Não envia arquivos para servidores externos.

# Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Web Audio API
- Lucide Icons

# Como utilizar

1. Acesse a aplicação.
2. Arraste um arquivo de áudio para a área indicada ou clique para selecionar.
3. Aguarde o processamento.
4. Reproduza o resultado na pré-visualização.
5. Clique em "Baixar áudio cortado".

O sistema extrai automaticamente os primeiros 30 segundos do arquivo original.

# Instalação

Não é necessário instalar dependências.

Basta baixar o projeto e abrir o arquivo "index.html" em um navegador moderno.

Publicação com GitHub Pages

1. Crie um repositório no GitHub.
2. Envie o arquivo "index.html".
3. Acesse Settings.
4. Entre em Pages.
5. Selecione Deploy from a branch.
6. Escolha a branch "main" e a pasta "/root".
7. Salve as configurações.

O GitHub Pages publicará a aplicação automaticamente.

Privacidade

Todo o processamento de áudio acontece localmente no navegador do usuário.

Nenhum arquivo é enviado para servidores externos.

A biblioteca Lucide Icons é carregada por CDN.

Formato de saída

Independentemente do formato original, o arquivo processado é disponibilizado em WAV.

Arquivos com menos de 30 segundos mantêm sua duração original.
